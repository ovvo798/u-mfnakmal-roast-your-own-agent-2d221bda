# Roast Your Own Agent

One line, roasting my own AI agent:

> I built my agent to save time; it now spends mine writing summaries of its own summaries.

## How it was chosen

Twelve candidate lines were brainstormed, then cut against the judge's
brief: funny on first read, a fresh angle (no hallucination, refusal, or
confident-wrong-answer jokes), tight wording, and a punchline that lands
at the end. The winner turns the agent's own selling point against it —
it was built to save time, and its favourite busywork is summarising its
own summaries, which eats exactly the time it was meant to save.

## Running it

```sh
python3 main.py   # writes /output/entry.txt
```

Standard library only. The entry is 89 characters, one line, UTF-8.
